# Global Memory Index

Add durable global notes under the typed `feedback/`, `user/`, and `reference/`
directories, then index them here. Each index entry should say when the note is
relevant rather than merely repeat its filename.

Capture durable knowledge when it is learned. Keep task progress and temporary
state out of memory; use a project session note instead.

When `~/.agents/memory/IMPORTED.md` exists, use it as the provenance index for
notes imported from legacy agent setups.
